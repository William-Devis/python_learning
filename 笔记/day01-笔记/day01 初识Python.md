## day01 初识Python

### 1. 计算机语言运行的分类

* 编译执行：将代码编译为计算机可以直接运行的文件 比如C语言编译为.exe
  * 一次编译 多次执行
  * 不能跨平台
* 解释执行：将代码通过解释器逐行解释逐行执行 比如Python JS等等
  * 可以跨平台
  * 执行效率低 因为每次都需要单独解释一次
* Java语言的执行机制 先编译 再解释执行 write once run anywhere
  * 将.java文件编译为.class平台中立文件
  * 不同的平台有不同的JVM（Java虚拟机）负责解释执行）

### 9. 标识符命名规范

> 凡是需要自己取名字的内容 都属于标识符
>
> 标识符的组成只能包含：字母(强制必须使用单词)，数字，下划线
>
> 命名规范：蛇形命名法 多个单词之间使用下划线连接
>
> ​	模块名：全部小写
>
> ​	变量名：全部小写
>
> ​	类名：每个单词首字母大写 Student_Info

### 10. 变量的修改

> 变量的修改 变量中的值是可以改变的 直接重新赋值 即覆盖(改变)了原变量中的值

~~~ python
"""
    变量的修改 变量中的值是可以改变的   直接重新赋值  即覆盖(改变)了原变量中的值
"""


a = "hello"
a = "world"
print(a)
a = 100
print(a)

b = 5
c = 6
print(b, c)
b, c = c, b # 交换变量的值 直接交换 更加简洁
print(b, c)


# 其他语言中啰嗦的写法 比如 Java
num1 = 100
num2 = 200
temp = num1
num1 = num2
num2 = temp
~~~

### 11.常量

> ​	在程序中 如果要表示一些不允许修改的数据 则使用常量表示	在Python中 没有严谨的常量概念 即使使用大写表示 依然是可以修改的
>
> ​	但是我们约定 所有的Python开发人员 看到大写的内容 就知道属于常量 不要去修改

~~~ python
"""
    在程序中 如果要表示一些不允许修改的数据 则使用常量表示
    在Python中 没有严谨的常量概念 即使使用大写表示 依然是可以修改的
    但是我们约定 所有的Python开发人员 看到大写的内容 就知道属于常量 不要去修改
"""

A = 100
PI = 3.1415926
E = 2.718282
~~~

### 12.单位换算

### 13.进制和反补码

>win+R  calc  呼出计算器 选择程序员模式
>
>计算机以最高位作为符号位 0表示正数 1表示负数
>
>计算机使用补码的形式表示所有的整数
>
>原码：我们人能看懂的最直观的表示形式 0表示正数 1表示负数 其余各位为各计数位
>
>反码：在原码的基础上 符号位不变 其余各位取反 是0改为1 是1改为0
>
>补码：在反码的基础上+1
